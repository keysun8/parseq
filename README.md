# PARSeq_Indic_HTR
Experimenting on PARSeq for Indic HTR

Place the datasets in the appropriate paths, follow https://github.com/baudm/parseq/blob/main/Datasets.md

Check the paths where outputs will be saved and change accordingly. 

place the charset file in configs folder. Some charsets are already present. 

Change the charset name in main.yaml inside configs folder and any other hyperparameter changes if needed. 

change the gnode and epochs and gpus in train.sh and the code should run.
